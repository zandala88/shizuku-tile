# 界面与磁贴等待反馈

用户已确认 1.0.0 功能可用，要求优化界面，并让点击磁贴后的等待过程有明确效果。

界面使用原生卡片布局，跟随系统深浅色。服务状态为主要内容，添加磁贴为主操作；
授权码设置默认折叠，已有授权码仍可修改，无需增加配置项。

磁贴点击后先更新视觉状态，再发送命令。等待期间主标题显示“正在启动…”或“正在停止…”，
图标以缓存的圆环帧轮换；完成、超时或关闭面板即停止动画。仅修改副标题在某些厂商面板上不够明显，
原生 Icon 不提供跨厂商可靠的动画控制，因此使用小尺寸位图图标帧，文字作为稳定反馈。
保持真实启停状态对应的明暗颜色，控制器拦截重复点击，不用 unavailable 将等待提示淡化。
未知状态仍禁止启停。启停期间 250ms 查询，首次状态确认间隔 200ms，稳定状态仍为 750ms。

沿用签名、包名、授权码和启停协议，升级为 1.1.0，通过 ADB 覆盖安装。
验证包括行为回归、Lint、签名，以及连接手机上的界面截图检查。旋转效果由系统面板实际刷新能力决定。

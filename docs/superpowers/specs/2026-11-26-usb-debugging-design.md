# 停止时关闭 USB 调试

用户要求一个选项，决定通过磁贴停止 Shizuku 时是否同时关闭 USB 调试。

开关默认关闭，保存至应用私有设置。开启后仅在本应用发起 STOP 并确认服务停止成功时，
将 Settings.Global.ADB_ENABLED 写为 0；启动、外部停止、广播失败、状态未知或停止超时均不触发。
启动仍使用原 Shizuku START 广播，不改变其自动打开 USB 调试的行为，也不修改无线调试。

上游 STOP 广播不接受关闭 USB 的参数。使用可通过 ADB 一次性授予的 WRITE_SECURE_SETTINGS，
避免新接入 Shizuku 执行 API 或 root。未授权时不能开启选项，页面提供复制授权命令的入口；
丢失权限时仍尝试停止 Shizuku，但明确提示 USB 调试未关闭。

关闭面板后，只有待完成的关闭 USB 操作继续短暂查询至停止完成或原 60 秒截止时间；
无需常驻服务。待完成标记随 STOP/deadline 保存，重建时恢复；完成、失败和超时后清除。

设置页新增“停止时关闭 USB 调试”卡片，显示会断开 USB ADB 的操作后果。
使用原签名覆盖升级为 1.2.0。测试默认行为、开启行为、授权、时序、外部停止、关闭面板和进程重建。
真机若测试关闭 USB，将预先安排独立的 shell 定时恢复以维持开发连接，并恢复初始状态。
